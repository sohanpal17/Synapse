Synapse

The Smart Litigation Management System

Collaborative legal workspace with TimeTree-style scheduling, offline-first architecture, and automated compliance tools.

✨ Key Features

📅

Shared Firm Calendar

TimeTree-style unified calendar with color-coded events (Hearings, Meetings, Deadlines) and contextual chat within each event.

📋

Dual-Tier Work Allocation

Separate Tasks (quick admin items) from Assignments (substantive legal work with progress tracking & review stages).

🔒

Conditional Privacy

Work stays private until deadlines are missed, then auto-escalates to public visibility for accountability.

🚦

Traffic Light Urgency

Visual indicators: 🟢 Green (>7 days), 🟡 Yellow (3-7 days), 🔴 Red (<48 hours) - works offline!

🆘

Courtroom SOS

Panic button for interns - instantly alerts senior counsel with court room & item number details.

📴

Offline-First Mode

Full functionality in court dead zones - auto-syncs when connectivity is restored.

⏱️

Limitation Calculator

Auto-calculate filing deadlines with 15-day, 7-day, and 1-day reminder scheduling.

📄

One-Tap Documents

Generate Exemption (205/317), Bail, and Adjournment applications pre-filled with case details.

💬

Contextual Chat

Discuss strategy inside each calendar event - no more scattered messages across apps.

🚀 How to Run

cd path/to/Synapse
flutter pub get
flutter run -d chrome

📡 Share with Friends (Same Wi-Fi)

flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8080

Then open http://YOUR_IP:8080 on any device!

🧭 Navigation Guide

👔 Senior Lawyer

Dashboard → Synapse Tools section → Calendar, Limitation Calc, Doc Generator, Assignments

👤 Junior Lawyer

Dashboard → Quick Tools section → Courtroom SOS, Firm Calendar, Limitation Calc, Doc Generator

💼 Client

Dashboard → Case card → Progress timeline → Documents, Calendar, Lawyer Contact

📅 Shared Calendar (TimeTree)

Senior Dashboard → Calendar button OR Junior → Firm Calendar button → Tap any event to open contextual chat
